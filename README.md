# Motion-Controlled-Stack-LED-game
8x8 LED dot matrix connections to Arduino nano

MAX7219 Pin	 Nano Pin
VCC	           5V
GND            GND
DIN	           D11
CLK	           D13
CS	           D10

Push button connections
Button  	   Nano Pin
One side    	 D2
Other side  	 GND

Ultrasonic sensor connections (HC- SR04)
HC-SR04 Pin	  Nano Pin
VCC	            5V
GND	            GND
Trig	          D3
Echo	          D4
