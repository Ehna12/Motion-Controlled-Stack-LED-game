# Motion-Controlled-Stack-LED-game

## 8×8 LED Dot Matrix Connections to Arduino Nano

### MAX7219 Pin → Nano Pin

| MAX7219 Pin | Nano Pin |
| ----------- | -------- |
| VCC         | 5V       |
| GND         | GND      |
| DIN         | D11      |
| CLK         | D13      |
| CS          | D10      |

## Push Button Connections

### Button → Nano Pin

| Button     | Nano Pin |
| ---------- | -------- |
| One side   | D2       |
| Other side | GND      |

## Ultrasonic Sensor Connections (HC-SR04)

### HC-SR04 Pin → Nano Pin

| HC-SR04 Pin | Nano Pin |
| ----------- | -------- |
| VCC         | 5V       |
| GND         | GND      |
| Trig        | D3       |
| Echo        | D4       |
